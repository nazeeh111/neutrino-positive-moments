# Independent reality check: moment uncertainty and scientific value

Reviewed 2026-11-01. This is a bounded decision review, not another implementation or benchmark. I inspected the current README, CLAIMS, continuous-comparator report and physical-usecase review, and refreshed the primary public dataset metadata. No core, experiment, paper or environment was changed.

## Decision

Do not build another uncertainty backend or run another grid around the failed counter-flux experiment. The current evidence supports preserving a mathematical research candidate, with unresolved priority, while stopping algorithmic-impact claims for this route. A genuinely different, independently justified physical constraint or decision problem would be needed to justify further implementation. Uncertainty itself cannot repair the failed exclusion gate.

This is not a finding that the mathematics is uninteresting or wrong. The sharp constrained extrema could still merit a focused theoretical publication after priority/usefulness review. It is a finding that more uncertainty machinery has not earned its cost as the next step toward the stated high-impact algorithm objective.

## A decisive monotonicity argument, with no solver required

Let Theta0 be the nominal moment class and Theta1 a moment-uncertainty class containing it. Define A(Theta) as the set of physical frequencies for which SOME positive angular completion in Theta solves the original dispersion relation at the specified physical wave vector. Then

    Theta0 subset Theta1  implies  A(Theta0) subset A(Theta1).

The proof is the same completion: a witness admitted at the nominal moments remains admitted when the allowed moments are broadened. Real current/matter shifts must be applied consistently for each completion; keep physical frequency and wave vector fixed rather than silently comparing different physical problems at a fixed reduced coordinate.

Consequently every one of the eight nominally compatible quantum-closure modes remains possible under any honest uncertainty set containing the nominal moments. A larger uncertainty box cannot produce the missing extra-information exclusion. Changing the criterion from existential compatibility to a universal claim would be a different scientific question and would require a separately declared decision problem. It would not turn this gate into a success.

The argument does not rule out useful robust exclusions elsewhere. It rules out the proposed continuation as a rescue of the current failed benchmark.

## What uncertainty can reveal about the exact-boundary advantage

An elementary example already resolves the concern without a new experimental pipeline. For equal species mass N and zero flux at fixed positive k, the proved longitudinal squared-growth cap is

    B(N)=N² k/(k+2N).

It is strictly increasing, with

    d log B / d log N = 2 - 2N/(k+2N),

which lies strictly between one and two. At the exact boundary gamma²=B(N0), a symmetric allowed common-density perturbation N0(1±epsilon), for any 0<epsilon<1, contains both an unattainable case (lower N) and an attainable case (higher N). The signed mass and flux remain zero, so this illustration introduces no changing real current shift. This is a sensitivity observation, not a model of measured error and not a failure of the exact theorem.

Thus the demonstrated exact-boundary classifications should remain mathematical guarantees for known inputs. They are not evidence that the same yes/no distinction is scientifically resolvable from noisy transport estimates. A frequency separated from the entire enlarged uncertainty set could still be robustly excluded. No claim that all exclusions disappear is justified.

## Current empirical evidence does not supply an uncertainty experiment

The strong continuous comparison is already unfavorable to a generic efficiency claim: the median paired conic generation-plus-checking cost is 0.737 times the geometric cost on jointly certified cases. Exact geometry supplies complete designed-boundary coverage; it does not supply a demonstrated overall runtime advantage.

The fixed M2 test supplied a physical-source opportunity with exact controlled inputs and failed its utility criterion: all eight growing closure modes are compatible. More moment uncertainty weakens that existential information, rather than adding a constraint.

I refreshed the [primary 2024 Zenodo dataset metadata](https://zenodo.org/records/13679313). It documents initial and final number four-fluxes, measured growth rates and merger-snapshot provenance. A field named F4_final_stddev is explicitly the variation in the final-state time series being averaged; it is not an error covariance for the initial supplied moments. The listed schema does not establish independent initial M2 tensors or a calibrated initial-moment uncertainty model. No archive bytes were downloaded, so schema completeness beyond the description is not asserted.

In particular, an arbitrarily chosen error level such as 0.1% or 1% would be a sensitivity study, not a realistic uncertainty experiment. The initial-state error bars, correlations, closure bias and numerical convergence must not be invented from the final-state variation.

## Conditions that would justify reopening this branch

Before additional implementation, obtain all of the following for one narrow experiment:

1. An actual physical validation decision that changes when a robust exclusion or upper bound crosses a specified threshold.
2. Initial number-moment provenance, including a defensible uncertainty set and correlations, or an independently supplied additional angular/occupation constraint. Do not promote a closure estimate into supplied truth.
3. An information class matching the axial model, or an explicitly proved reduction from the actual geometry. A projected general 3D flux is not automatically an axial stability problem.
4. A declared pass/fail comparison against a conventional continuous optimization method, including proof generation and checking if certification is the benefit.

If these inputs are absent, retain the paper, code and negative results as the strongest defensible mathematical contribution; seek focused external priority/usefulness review when authorized, or pivot the high-impact algorithm search. Do not weaken the failed gate, widen its grid or relabel uncertainty sensitivity as practical impact.
